# Runtime Components

This repository contains my personal runtime component configuration files.

## Files

- `.bashrc` - Bash shell configuration
- `.zshrc` - Zsh shell configuration
- `.vimrc` - Vim configuration
- `.gdbinit` - GDB debugger configuration
- `.gitconfig` - Git configuration
- `install.sh` - Script for installing the configuration files

## Installation

Clone this repository and run:

    ./install.sh

The installation script backs up existing configuration files before replacing them.
